# Лабораторная работа №4 — GitHub и ветвление

Демонстрационный проект для Visual Studio 2019 / .NET Framework 4.8.

В проекте показаны:

- локальный Git-репозиторий;
- последовательные commit;
- отдельная ветка `Addfunction`;
- добавление функциональности во второй ветке;
- слияние `Addfunction` -> `master`;
- просмотр истории.

Для публикации на GitHub нужно создать репозиторий в аккаунте пользователя и выполнить `git remote add origin ...`, затем `git push -u origin master`.
